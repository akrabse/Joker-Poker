# Beoordelingsformulier voor de Docent (Joker-Poker Project)

Dit formulier is ontwikkeld om het eindproject van 5 HAVO / 6 VWO leerlingen (in hun examenjaar) gestructureerd en objectief te kunnen beoordelen. De beoordeling is opgedeeld in transparante stappen, waarbij per voltooid onderdeel punten behaald worden.

## 1. Project Management & Verslaglegging (Totaal: 2 punten)
- **[ ] Opzetten van een logboek (1 punt)**  
  *De leerling heeft een gestructureerd logboek bijgehouden waarin per moment staat beschreven wat er is gedaan, tegen welke problemen men aanliep en hoe die zijn opgelost.*
- **[ ] Reflectie en Planning (1 punt)**  
  *De leerling kan aantonen dat er vooraf nagedacht is over de stappen, en kan inhoudelijk reflecteren op het eigen leerproces.*

## 2. Versiebeheer met Git (Totaal: 2 punten)
- **[ ] GitHub account & Git installatie (1 punt)**  
  *De leerling heeft succesvol een GitHub account aangemaakt, en Git lokaal gedownload en geïnstalleerd.*
- **[ ] Git Push & Commits (1 punt)**  
  *De leerling kan aantonen dat de code met succesvolle `git push` commando's naar de repository is gestuurd, voorzien van duidelijke commit-berichten.*

## 3. Deployment & Hosting (Totaal: 2 punten)
- **[ ] Vercel Hosting (1 punt)**  
  *De website is succesvol gekoppeld aan Vercel en is online te bekijken door de docent via een werkende link.*
- **[ ] MongoDB Database (1 punt)**  
  *Er is een database cluster aangemaakt via MongoDB Atlas en deze is succesvol verbonden met de website om gegevens in op te slaan.*

## 4. Codekwaliteit & Documentatie (Totaal: 2 punten)
- **[ ] Overzichtelijkheid en Structuur (1 punt)**  
  *De bestanden zijn logisch ingedeeld in mappen (bijv. frontend en backend) en de code is netjes uitgelijnd.*
- **[ ] Code Commentaar & Uitleg (1 punt)**  
  *Elk codebestand bevat aan het begin een duidelijke Nederlandse uitleg. Bij nieuwe of complexe stukjes code is met inline-commentaar exact aangegeven wat die code uitvoert.*

## 5. Functionaliteit & Resultaat (Totaal: 2 punten)
- **[ ] Werking van het Project (1 punt)**  
  *De gemaakte applicatie (Joker-Poker) werkt naar behoren, met inzet van de basiselementen van HTML/JS en backend logica.*
- **[ ] Vormgeving en Inzet (1 punt)**  
  *De interface ziet er representatief uit, eventueel door gebruik te maken van de aangereikte inspiratiebronnen; de leerling heeft zich verdiept in CSS.*
